# おしめぐ（Oshi-Megu）

推しへの想いはそのままに、お金の流れだけ、整える。

推し活を続けながら、無理なくお金を整えるためのアプリです。
記録はすべて端末の中だけに保存され、どこにも送信されません。

---

## 📱 アプリを開く

### 👉 [https://manamana-hue.github.io/oshimegu/](https://manamana-hue.github.io/oshimegu/)

初めての場合は、開いたあと Chrome のメニュー（⋮）から
**ホーム画面に追加** しておくと、アプリのように使えて記録も長く残せます。

---

## 🔧 アプリを更新する（スマホからでもできます）

### 👉 [ファイルをアップロードする画面をひらく](https://github.com/manamana-hue/oshimegu/upload/main)

上のリンクをタップ → **choose your files** → 新しい `index.html` を選ぶ
→ 下までスクロールして緑の **Commit changes**。

**差し替えるのは `index.html` だけです。** `sw.js` はもう変える必要がありません。

1〜3分で反映されます。アプリを開くと画面下に「新しい版があります」と出るので、
**更新する** をタップしてください。**記録は消えません。**

> 版数は `index.html` の中の `APP_VERSION` だけで管理しています。
> `sw.js` はその値を受け取る作りなので、差し替え不要です。

---

## 📂 ファイルの構成

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（画面・計算・保存すべて） |
| `sw.js` | オフラインで動かすための仕組み（もう差し替え不要） |
| `manifest.webmanifest` | ホーム画面に追加するための設定 |
| `brand/` | アイコン |

**更新のときに差し替えるのは `index.html` だけです。**

うまく動いているかは、アプリの 設定 → **保存について** で確認できます。
「オフライン対応」に *動いています* と出ていればOKです。

---

## 💾 記録の持ち出しと引き継ぎ

同期の仕組みは入れていません（外部に一切送らない設計のため）。
端末を変えるときは、控えのファイルで移します。

1. 移す側：設定 → **控えを保存する（JSON）**
2. そのファイルを新しい端末へ渡す
3. 受け取る側：設定 → **控えから戻す**

長く使う場合は、ときどき控えを保存しておくと安心です。

---

## ⚠️ 記録が消えたように見えたら

まずURLを確認してください。ブラウザはURLごとに記録を分けて持つため、
別のURLで開くと、記録が無いように見えます。

`https://manamana-hue.github.io/oshimegu/` で開いていれば残っています。
